# FerriX
Recreation of the [CalculiX Solver](https://www.calculix.de/) by Guido Dhondt, meant for educational purposes.
This solvers aims to work with the same input file structure, so it can be used as a drop-in replacement for a small subset of supported problems.

## Installation

See the releases tab to download prebuilt binaries or use
```
cargo install --git https://github.com/KwentiN-ui/ferrix.git
```
to compile the newest version yourself. This will also make the tool available as `ferrix` in your terminal.
